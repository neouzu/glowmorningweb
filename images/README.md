# 이미지 폴더

## 필요한 이미지

### hero-study.jpg
- **위치**: `/images/hero-study.jpg`
- **설명**: 히어로 섹션에 표시될 여성이 아침 햇살을 맞으며 커튼을 여는 이미지
- **제공된 이미지**: 따뜻한 아침 햇살이 들어오는 창가의 여성 (미라클 모닝 컨셉과 완벽하게 일치)
- **형식**: JPG, PNG
- **용도**: 나중에 동영상으로 대체될 예정

## 이미지 추가 방법

### 제공된 이미지 저장하기

1. 채팅에서 제공받은 여성이 커튼을 여는 이미지를 다운로드
2. 파일명을 `hero-study.jpg`로 변경
3. 이 폴더(`/images/`)에 저장

### 또는 직접 추가

```bash
# 프로젝트 루트에서
cd images/
# 이미지 파일을 여기에 hero-study.jpg 이름으로 저장
```

## 완료 후

이미지를 추가한 후 브라우저에서 확인하면 히어로 섹션 오른쪽에 아름다운 아침 햇살 이미지가 표시됩니다.
