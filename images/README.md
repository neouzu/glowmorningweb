# 이미지 폴더

## 필요한 이미지

### hero-study.jpg
- **위치**: `/images/hero-study.jpg`
- **설명**: 히어로 섹션에 표시될 여성이 공부하는 이미지
- **권장 크기**: 최소 1200px x 1600px (세로형)
- **형식**: JPG, PNG
- **용도**: 나중에 동영상으로 대체될 예정

## 이미지 추가 방법

1. 제공받은 여성 공부 이미지를 `hero-study.jpg` 이름으로 이 폴더에 저장
2. 또는 임시로 다른 이미지를 사용하려면 동일한 파일명으로 저장
